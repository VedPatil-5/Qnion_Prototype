# Rules and validation

## 1. Purpose

This document governs how Qnion describes onion grading standards, inspection findings, prototype data, and assistant answers.

## 2. Standards reference

In onion procurement and grading (e.g. APMC / NAFED / NCCF standards):
- **Grade A**: Sound, well-cured bulbs of uniform size, shape, and colour, free from rotting, doubles, and significant damage.
- **URS (Under-size / Re-sortable / Sortable)**: Bulbs with minor skin blemishes, slight sprouting, or smaller bulb diameters requiring segregation.
- **Rejected**: Rotten, decayed, hollow, or diseased bulbs that must be removed immediately to prevent batch spoilage.

## 3. Fixture finding rules

- Every defect/finding in sample fixtures specifies a code (ROTTEN, SPROUTED, UNDERSIZED, DAMAGED), severity, badge (Rejected / URS), description, and practical quality guidance.
- Grade breakdown percentages (Grade A, URS, Rejected) must sum to 100%.
- Bounding boxes provide representative coordinates on sample photos for demonstration.
